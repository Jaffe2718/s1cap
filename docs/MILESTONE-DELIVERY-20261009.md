## S1CAP 默认配置

`bench/cells/C2.json` 改为 `tas.updatePolicy=milestone`、`tMaxChars=2400`。
DSH/TAS 对照预设不变。显式 profile 的覆盖仍优先，旧 profile 若明确写 perTask，
仍采用旧行为；启动 wiring 记录实际策略，不能仅凭预设认定新策略已启用。

milestone 是在线调优策略，区别于旧 TAS 的静态完整 trace 序列化；不宣称复现论文的同一实验条件。
它在本地提取源记录，不额外调用 LLM：

- 最近明确的根因陈述作为模型观点摘录，修正后的判断替代旧判断；常规计划不推进状态。
- 按 toolCallId 匹配成功写入/编辑结果；只调用工具不算完成。
- 保留最近三条不同测试命令的结果证据。同命令后来失败覆盖先前成功，新编辑清空旧代码的验证记录，未完成的工具不算已验证。
- 没有进展证据时冻结首个非空 trace；新任务清空状态。状态未变时字节保持稳定。

这是规则提取，不是通用语义状态识别器：未覆盖的工具、命令、语言或输出格式会保守地不更新。
不会把一次测试通过解释为整题完成，也不阻止模型重新验证。
状态通过原生追加通道交付，旧状态仍可能保留在宿主历史中；没有改写历史消息或清除缓存前缀。
