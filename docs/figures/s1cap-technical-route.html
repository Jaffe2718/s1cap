S1CAP Technical Route

one user turn = many LLM steps · S1CAP is a hook, not a stage · stopping belongs to the model

Module roles

  • User Turn x — user input · tool results · traces
  • Run + Verify — self-loop: next LLM step, or the model stops
  • Stop · Model — the only exit; S1CAP cannot veto it
  • System-2 LLM Step — one step: think · act · call tools
  • ASSEMBLER — per LLM call: BFS(τ,d) + budget + TAS layout
  • PLAN GATE — reorders the model's plans, never vetoes
  • Assoc. Graph — weighted edges, w·exp(−Δt/λ) decay
  • RG Upkeep — async tap: scores new events, may lag
  • S1 Assoc / Decide — noul relevance · choice scoring

Loop · authority · async

  • One user turn = many LLM steps (think · act · tool)
  • ASSEMBLER runs before every LLM call, not per turn
  • RG upkeep is silent and async: it may lag behind
  • Stopping is the model's call; S1CAP cannot veto it
  • Surface rewrite: model view only; transcript intact
  • Telemetry: session log + control-plane log, split
